# 草坪守卫战 · Lawn Guardians

一款原创网页植物塔防游戏。收集阳光、选择植物卡片，在五条草坪上建立防线并击退三波入侵者。

## 已实现

- 五行九列草坪与逐步增强的三波敌人
- 六种植物：暖阳花、豆荚藤、双生藤、岩壳根、霜叶蕨、爆浆果
- 阳光收集、卡片冷却、铲除、草坪清扫机、暂停与二倍速
- 三类不同生命值和速度的敌人
- 胜负结算、本地最高分、键盘快捷键与响应式界面
- 原创开场主视觉与轻量网页动画

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

浏览器打开 `http://localhost:3000/`。

生产构建：

```bash
npm run build
```

## 操作

- `1`–`6`：选择植物
- 鼠标或触屏点击：种植 / 收集阳光
- `Space`：暂停或继续
- `Esc`：取消当前选择
- 右上角按钮：音效、游戏速度和暂停
