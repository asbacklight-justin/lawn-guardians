# 路线图

路线图用于表达方向，不构成发布时间承诺。

## 0.2 — 可重复游玩

- 连续远征模式（已完成：四关连战与跨关状态保留）
- 可复现的随机种子
- 难度选项与关卡评级
- 关卡内新手提示
- 更完整的引擎单元测试

## 0.3 — 内容扩展

- 至少 4 种新植物
- 至少 3 种新敌人
- 白天、黄昏和雨夜场景
- 特殊地形与行内障碍
- 图鉴和成就

## 0.4 — 表现力

- 原创音乐和更丰富的 Web Audio 音效
- 角色受击、死亡和技能动画
- 粒子质量设置
- 更完善的移动端横屏体验

## 1.0 — 稳定版

- 独立的游戏引擎模块
- 完整的自动化测试
- 可配置关卡数据
- 存档迁移策略
- 中英文界面
- 性能和无障碍审计

- 修正文档
- 改善键盘操作
- 增加测试
- 优化小屏布局
