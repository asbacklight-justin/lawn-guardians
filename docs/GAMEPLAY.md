# 玩法与数值

## 目标

在敌人突破房屋前完成夕照前院、月雾墓园和潮汐玻璃屋的防守，或在无尽模式中挑战尽可能远的站次。

## 核心循环

1. 收集从天空落下或暖阳花产生的阳光。
2. 消耗阳光选择并种植植物。
3. 根据敌人所在行补充输出、防御或控制。
4. 在卡片冷却和有限资源之间做取舍。
5. 击退当前关卡全部敌人后获胜。

按 `A` 或点击阳光栏的“全收”按钮，会按生成顺序、每隔约 110ms 自动收集一次按键时已经存在的全部阳光。之后新生成的阳光需要再次触发。

## 关卡与波次

### 第一关：夕照前院

- 第一波：以游荡者为主，少量陶盆客
- 第二波：陶盆客增多，并开始出现铁盔客
- 第三波：重装单位占比显著提高

### 第二关：月雾墓园

- 五块墓碑固定占据种植格，不能被铲除或种植
- 自然阳光生成更慢，但初始阳光略高
- 共四波、40 名敌人
- 敌人生命、移动速度和攻击力约提高 8%
- 第四波铁盔客占比最高
- 解锁可穿透三名敌人的月芒菇

### 第三关：潮汐玻璃屋

- 共五波、50 名敌人，基础属性比第一关约高 14%
- 开局 7 秒后，潮水从第一行开始按顺序轮流淹过五条路线
- 每条路线被淹约 7 秒，随后约 6 秒进入下一次潮汐前的间歇
- 潮水中的敌人移动速度降至原来的 38%
- 被淹路线上的所有植物暂时停止攻击和生产，离潮后继续原有计时
- 需要把输出和阳光生产分散到多条路线，不能只依赖单行火力

### 无尽模式

- 从第一关开始，按夕照前院 → 月雾墓园 → 潮汐玻璃屋循环
- 关卡完成后直接进入下一站，不出现胜利结算
- 阳光、已种植物、植物当前生命、卡片冷却和得分全部保留
- 新战场会补充清扫机；墓碑只在没有植物占据的预定位置出现
- 每完成一站，敌人生命、速度和攻击约提高 6%
- 每完成一轮三关，后续关卡额外增加 5 名敌人
- 无尽模式抵达第二站后解锁月芒菇，之后即使循环回第一关也会保留

所有关卡的敌人出生行随机，生成间隔随波次缩短，并带少量随机浮动。

## 得分

- 收集一份阳光：10 分
- 游荡者：90 分
- 陶盆客：150 分
- 铁盔客：260 分
- 清扫机击退：每名 70 分
- 获胜：根据通关时间获得额外奖励

最高分只保存在当前浏览器。

## 平衡原则

- 资源植物应在约 2–3 次产出后收回成本
- 输出植物的单位费用伤害不应让高费卡失去价值
- 岩壳根应能为基础输出争取明显但有限的时间
- 爆浆果可以解决局部危机，但长冷却阻止持续依赖
- 第三波必须要求玩家利用至少两种不同定位的植物
- 第二关墓碑应改变布阵，但不能造成无解行
- 月芒菇在密集波次中应优于单发植物，但对单体不应全面替代豆荚藤
- 第三关潮汐应创造阵型轮换压力，同时给被淹行提供敌人减速补偿
- 无尽模式的跨关保留应奖励长期规划，但敌人强化必须逐步压缩安全空间

修改数值时应至少完整游玩两局：一局偏资源开局，一局偏快速输出开局。
