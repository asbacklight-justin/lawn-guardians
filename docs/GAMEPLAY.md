# 玩法与数值

## 目标

在敌人突破房屋前击退三波入侵者。

## 核心循环

1. 收集从天空落下或暖阳花产生的阳光。
2. 消耗阳光选择并种植植物。
3. 根据敌人所在行补充输出、防御或控制。
4. 在卡片冷却和有限资源之间做取舍。
5. 击退全部 30 名敌人后获胜。

## 初始条件

| 项目 | 数值 |
| --- | ---: |
| 草坪行数 | 5 |
| 草坪列数 | 9 |
| 初始阳光 | 150 |
| 敌人总数 | 30 |
| 波次数 | 3 |
| 每行清扫机 | 1 |
| 普通速度逻辑步长 | 0.05 秒 |

每份阳光价值 25 点。天空阳光约每 5.7–7.1 秒出现一次，暖阳花约每 7.5 秒产生一次。

## 敌人数值

| 敌人 | 生命 | 移动速度 | 每秒攻击 | 定位 |
| --- | ---: | ---: | ---: | --- |
| 游荡者 | 190 | 0.20 格/s | 58 | 基础单位 |
| 陶盆客 | 410 | 0.15 格/s | 64 | 中等护甲 |
| 铁盔客 | 720 | 0.115 格/s | 72 | 重装单位 |

减速生效时移动速度约为原来的 48%。

## 波次构成

- 第一波：以游荡者为主，少量陶盆客
- 第二波：陶盆客增多，并开始出现铁盔客
- 第三波：重装单位占比显著提高

敌人出生行随机，生成间隔随波次缩短，并带少量随机浮动。

## 得分

- 收集一份阳光：10 分
- 游荡者：90 分
- 陶盆客：150 分
- 铁盔客：260 分
- 清扫机击退：每名 70 分
- 获胜：根据通关时间获得额外奖励

最高分只保存在当前浏览器。

## 平衡原则

- 资源植物应在约 2–3 次产出后收回成本
- 输出植物的单位费用伤害不应让高费卡失去价值
- 岩壳根应能为基础输出争取明显但有限的时间
- 爆浆果可以解决局部危机，但长冷却阻止持续依赖
- 第三波必须要求玩家利用至少两种不同定位的植物

修改数值时应至少完整游玩两局：一局偏资源开局，一局偏快速输出开局。
