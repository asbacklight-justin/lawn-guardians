# 素材与版权说明

## 项目原则

本项目重现的是通用的分路资源塔防机制，不复制商业游戏的受保护表达。

禁止提交：

- 《植物大战僵尸》或其他游戏提取的图片、音频、字体、动画和代码
- 容易被误认为官方角色、商标或界面的高相似度复刻
- 未取得再分发授权的网络素材
- 带有来源不明水印的素材

## 新增素材要求

贡献者添加素材时，应在 Pull Request 中说明：

- 作者或来源
- 创建方式
- 许可证名称与链接
- 是否允许修改和再分发
- 是否包含商标、人物肖像或第三方受保护元素

建议优先使用：

- 自己创作的素材
- CC0 / 公共领域素材
- 明确允许商用、修改和再分发的素材
- 代码生成的 CSS、Canvas 或 Web Audio 内容

如果授权条件要求署名，请把信息补充到本文件。
